Limitación de la copia local
El dump de esquema no contenía las políticas personalizadas de storage.objects que sí aparecieron en la inspección de producción. El SQL incluye DROP POLICY IF EXISTS para reemplazar la política de lectura conocida y crea reglas de lectura aprobada, lectura total para admin y subida para admin. Las pruebas validan el estado esperado después de aplicar la corrección, no la transición desde todas las políticas originales del proyecto.

No se modificó ni desplegó nada en producción. El archivo SQL queda para revisión y ejecución manual del usuario.
